# تشغيل Dyar Connect — الخريطة الحية والتتبع بالمتر

أول قطعة **عاملة فعليًا** من النظام: خادم لحظي + خريطة حقيقية (OpenStreetMap) تعرض
موقع كل جهاز بدقة GPS الفعلية بالمتر، مع صفحة موصل تعمل على UR5 وأي هاتف من المتصفح مباشرة — قبل بناء تطبيق APK.

**صفحة الموصل فيها ميزات الجهاز كاملة** (مثل شاشة Zello على UR5): زر PTT دائري كبير
اضغط مطولًا = يسجل، اترك = يبث لكل الأجهزة ولوحة التحكم فورًا · 🔁 إعادة آخر رسالة ·
🚨 زر طوارئ (ضغط 3 ثوانٍ) يفتح موقعك في غرفة العمليات مع إنذار · رسائل نصية · اسم القناة وعدد المتصلين.
ولوحة التحكم فيها زر «🎙 تحدث» يبث لكل الأجهزة، وقسم «البث الحي» يشغّل كل بث وارد تلقائيًا.

**🧕 تاليا — الموزعة الآلية:** عند إنشاء أي طلب تعرضه تاليا تلقائيًا على أقرب موصل متاح
(صوتًا ونصًا مع مهلة 25 ثانية وأزرار قبول/رفض على جهازه) — رفضٌ أو صمت ← تنتقل للتالي،
وبعد 3 محاولات تصعّد لغرفة العمليات. وكل إعلانات اللوحة تصل الأجهزة بلسان تاليا منطوقة.

**🛡 أمان:** رمزان منفصلان — `DYAR_PIN` للأجهزة و`OPS_PIN` للوحة العمليات (اضبط الاثنين في
الإنتاج؛ إن لم يُضبط OPS_PIN يُستخدم رمز الأجهزة مؤقتًا). إدارة الأجهزة من اللوحة: اختر
موصلًا ← ✏️ تسمية · ⛔ فصل فوري (جهاز مفقود) · 🗑 حذف من السجل.
والدمج مع لوحة العقل (غرفة التشغيل): [brain-integration.md](brain-integration.md).

## 1. التشغيل على جهازك

```bash
cd server
npm install
npm start
```

سيطبع الخادم:

```
لوحة التحكم:  http://localhost:8080/
من الشبكة:    http://192.168.x.x:8080/
صفحة السائق:  http://<العنوان>:8080/driver.html
رمز الربط PIN: 1234
```

- افتح **لوحة التحكم** في المتصفح وأدخل رمز PIN — تظهر خريطة شوارع حقيقية لمنطقة الجليل.
- للتجربة بدون أجهزة: في نافذة ثانية `npm run sim` — يظهر 4 موصلين وهميين يتحركون فورًا.

## 2. إضافة جهاز حقيقي (UR5 أو أي هاتف)

1. في لوحة التحكم اضغط **«➕ إضافة جهاز»** — يظهر رمز QR ورابط صفحة السائق.
2. على الجهاز: امسح الرمز (أو اكتب الرابط في المتصفح) → أدخل اسم الموصل ورمز PIN → **ابدأ الإرسال**.
3. الجهاز يظهر فورًا في القائمة والخريطة مع: الإحداثيات، **دقة التحديد ±X متر** (ملونة: أخضر ≤8م، برتقالي ≤25م)، السرعة، البطارية، وعمر آخر تحديث.
4. اضغط على أي موصل في القائمة أو الخريطة → تقريب 16.5 (مستوى شوارع) + **تتبع مباشر** + خط مساره.

هوية الجهاز تُحفظ محليًا (localStorage) — يكفي الربط مرة واحدة لكل جهاز.

## 3. مهم: GPS يتطلب HTTPS خارج localhost

متصفحات Android الحديثة لا تسمح بقراءة GPS من صفحة `http://` إلا على `localhost`.
عندك ثلاثة حلول بالترتيب من الأسرع للأصح:

**أ) نفق مؤقت للتجربة (دقيقتان):**
```bash
# يعطيك رابط https عام مؤقت يمرر إلى خادمك المحلي
npx cloudflared tunnel --url http://localhost:8080
```
افتح الرابط الناتج على UR5 — يعمل GPS مباشرة.

**ب) شهادة ذاتية على شبكتك المحلية:**
```bash
openssl req -x509 -newkey rsa:2048 -nodes -keyout key.pem -out cert.pem -days 365 -subj "/CN=dyar"
TLS_CERT=cert.pem TLS_KEY=key.pem npm start
```
افتح `https://192.168.x.x:8080` على الجهاز واقبل تحذير الشهادة (مرة واحدة لكل جهاز).

**ج) الحل الدائم — النشر على Render بضغطة واحدة (مُجهَّز):**

1. افتح: **https://render.com/deploy?repo=https://github.com/matrix09876/Dyar.tv** (بنفس حساب Render الذي عليه غرفة التشغيل).
2. Render يقرأ `render.yaml` تلقائيًا — أدخل قيمة `DYAR_PIN` (رمز ربط الأجهزة) واضغط Deploy.
3. بعد دقائق يصبح لديك رابط دائم مثل `https://dyar-connect.onrender.com` — **HTTPS جاهز، فيعمل GPS والمايك مباشرة**، والأجهزة تتصل من أي مكان عبر شبكة الجوال.
4. **لتفعيل الجسر مع غرفة التشغيل:** انسخ قيمة `BRAIN_API_KEY` (ولّدها Render في خدمة dyar-connect) وأضفها في خدمة `egint-support` على Render كمتغيرين: `CONNECT_API_KEY` = نفس القيمة، و`CONNECT_URL` = رابط خدمة dyar-connect. (فرع الجسر في مستودع egint-support: `claude/dyar-connect-bridge` — ادمجه في main فينشر تلقائيًا.)

بديل: خادم VPS (مثل Hetzner) + نطاق `connect.dyar.tv` خلف Caddy — نفس النتيجة بتحكم أكبر.

## 4. عن الدقة «بالمتر» — بصراحة تقنية

- نطلب من الجهاز **أعلى دقة يوفرها العتاد** (`enableHighAccuracy`)، ونعرض لكل نقطة **هامش الدقة الفعلي** الذي يبلغ عنه GPS نفسه.
- هواتف حديثة في شارع مفتوح: عادة **±3–8 م**. أجهزة أقدم مثل UR5 أو بين مبانٍ عالية: ±10–30 م.
- هذا هو حد فيزياء GPS المدني نفسه — و**Zello وGoogle خاضعان لنفس الحد تمامًا**؛ الفرق أننا نعرض الهامش بشفافية بجانب كل جهاز بدل إخفائه.
- الخريطة نفسها دقيقة حتى مستوى 19 (أمتار قليلة لكل بكسل) مع مسطرة قياس بالمتر أسفل الشاشة.

## النشر الحيّ (منشور فعليًا)

الخدمتان تعملان الآن على Render ومرتبطتان ذاتيًا بلا أي إعداد يدوي:

| الخدمة | الرابط الحيّ |
|---|---|
| لوحة Dyar Connect (الخريطة + الطلبات + تاليا) | `https://dyar-connect.onrender.com` |
| **شاشة عقل ديار التنفيذي (تلفاز المكتب)** | `https://dyar-connect.onrender.com/kiosk.html` |
| غرفة التشغيل (لوحة العقل) | `https://egint-support.onrender.com` |

**تشغيل التلفاز:** افتح رابط الشاشة في متصفح التلفاز (أو صندوق تشغيل موصول بـHDMI)، أدخل رمز
اللوحة مرة واحدة، فعّل «🎙 يا ديار» واملأ الشاشة — ثم قُل: «يا ديار، كم طلبية أمس؟».
التفاصيل الكاملة: docs/executive-brain.md

- افتح لوحة Connect، أدخل رمز PIN، واضغط «➕ جهاز» لمسح QR على UR5.
- الربط بغرفة التشغيل تلقائي (تسجيل ذاتي مُثبَت الملكية) — طوارئ الأجهزة وأحداث الطلبات تصلها فورًا،
  وتاليا توزّع كل طلب جديد على أقرب موصل صوتيًا.

## 5. ماذا بعد؟

- **خرائط بدون إنترنت خارجي:** لاحقًا نستضيف بلاطات المنطقة محليًا (Protomaps/PMTiles — ملف واحد لكل الجليل) فلا نعتمد حتى على خوادم OSM.
- **الصوت PTT:** المرحلة التالية — LiveKit على نفس الخادم (docs/architecture.md §2).
- **تطبيق UR5 الأصلي (Kotlin):** خدمة خلفية دائمة + زر PTT الفيزيائي، بعد إثبات الحلقة الحالية.
- **الإنتاج:** PostgreSQL بدل الذاكرة، وJWT ديار بدل PIN — البنية جاهزة لذلك في التصميم.
